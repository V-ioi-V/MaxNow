# 芭蕾周记录手绘数字

这套素材用于芭蕾小红书周记录封面。`digit-0.png` 至 `digit-9.png` 是透明 PNG，不对应系统字体，也不依赖每周重新生成图片。

- 笔触基准：Owner 确认方向中的手绘数字 `2`。
- 固定颜色：`#6e2638`。
- 固定画布高度：`456px`。
- 固定基线：距画布顶部 `424px`。
- 每个文件保留 `24px` 左右留白，宽度随数字自然变化，避免 `1` 与其他数字组合时出现过大间距。
- `digits-preview.png` 只用于总览验收，不作为运行时素材。
- 运行时按 `manifest.json` 读取数字文件，依次绘制后将整个数字组水平居中；缩放时所有数字必须使用同一比例。

数字素材现由芭蕾页周记录封面正式使用；固定底图、北京时间周一自动加一、预览、下载和剪贴板复制均已接入。
